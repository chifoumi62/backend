pour lancer l'application:

1- lancer le front :
ouvrir un terminal et utiliser la commande "npm run strart"
apres vous etres placer au niveau du fichier frontend

2- lancer le serveur node :
se placer au niveau du fichier backend avec un nouveau terminal et lancer la commande 
"nodemon serveur"
le serveur devrait ecouter les evenement au niveau du port 4000 et afficher 
une erreur de connexion a mongodb
pour corriger cette erreur copier le code fourni dans le fichier texte dans le fichier ".env"
sauvegarder et vous devriez etres connecter a mongodb avec un serveur node
